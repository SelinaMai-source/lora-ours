# Suites

Each suite keeps the official published base intact and applies only the v1
overlay described in its README.

- `citb/`: Replay(50) base plus SSRG-aligned replay budget.
- `standard/`: O-LoRA base plus class-coverage SSRG and assess-retention gate.
- `arper/`: ARPER SCLSTM Path B plus SSRG exemplar selection.
- `todcl/`: ToDCL ADAPTER NLG anchor plus Assess-then-Update orthogonal penalty.
